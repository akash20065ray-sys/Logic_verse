# Context-Free Grammar (CFG) & Parsing Theory

Welcome to the **LogicVerse Context-Free Grammar (CFG) Module**. This guide provides a formal mathematical, algorithmic, and parsing breakdown of Context-Free Languages, Parse Trees, Chomsky Normal Form (CNF), and the CYK Parsing Algorithm.

---

## 1. Formal Definition of Context-Free Grammar

A **Context-Free Grammar (CFG)** is a 4-tuple:
$$G = (V, \Sigma, R, S)$$

- **$V$**: Finite set of **Non-terminal variables** (e.g. $\{S, A, B\}$).
- **$\Sigma$**: Finite set of **Terminal symbols** disjoint from $V$ (e.g. $\{a, b, 0, 1\}$).
- **$R$**: Finite set of **Production Rules** mapping a variable to a string of variables and terminals:
  $$R \subseteq V \times (V \cup \Sigma)^* \quad \text{written as } A \to \alpha$$
- **$S \in V$**: Designated **Start Symbol**.

The language generated by $G$, denoted $L(G)$, is the set of all terminal strings derived from $S$:
$$L(G) = \{ w \in \Sigma^* \mid S \Rightarrow^* w \}$$

---

## 2. Derivations & Parse Trees

A **derivation** is a sequence of production applications replacing variables $A \to \alpha$.

- **Leftmost Derivation**: The leftmost variable is always replaced first at each step.
- **Rightmost Derivation**: The rightmost variable is always replaced first at each step.
- **Parse Tree (Derivation Tree)**: A rooted ordered tree representing the hierarchical syntactic structure of a derivation:
  - Root: Start symbol $S$.
  - Interior nodes: Non-terminal variables $V$.
  - Leaf nodes: Terminals $\Sigma$ or empty string $\varepsilon$.

### Ambiguity:
A grammar $G$ is **ambiguous** if there exists a string $w \in L(G)$ that has **two or more distinct parse trees** (or leftmost derivations).
*Example*: Arithmetic grammar $E \to E + E \mid E \times E \mid \text{id}$.

---

## 3. Chomsky Normal Form (CNF)

A CFG $G$ is in **Chomsky Normal Form (CNF)** if every production rule is of the form:
$$A \to B C \quad \text{or} \quad A \to a \quad (\text{or } S \to \varepsilon \text{ if } \varepsilon \in L(G))$$
where $A, B, C \in V$ and $a \in \Sigma$, with $B, C \neq S$.

### Reduction to CNF Algorithm (4 Steps):
1. **New Start Symbol**: Add $S_0 \to S$ so start symbol never appears on right-hand side.
2. **Eliminate $\varepsilon$-productions**: Identify nullable variables ($A \Rightarrow^* \varepsilon$) and drop them from right-hand sides.
3. **Eliminate Unit Productions ($A \to B$)**: Replace $A \to B$ with $A \to \gamma$ for all $B \to \gamma$.
4. **Restructure Long Productions**:
   - Replace terminals in mixed strings with helper variables ($U_a \to a$).
   - Break strings of length $\ge 3$ into binary pairs: $A \to B C D \implies A \to B X_1, X_1 \to C D$.

---

## 4. CYK (Cocke-Younger-Kasami) Parsing Algorithm

The **CYK Algorithm** is a dynamic programming algorithm that tests whether a string $w = a_1 a_2 \dots a_n \in L(G)$ for a grammar $G$ in CNF.

### Dynamic Programming Table $P$:
$P[i, j, A]$ is true if substring $w[i \dots j]$ of length $l = j - i + 1$ can be derived from variable $A$.

### Algorithm Steps:
1. **Base Case (Length 1)**: For $i = 1 \dots n$:
   $$P[i, i, A] = \text{true} \iff (A \to a_i) \in R$$
2. **Inductive Step (Length $l = 2 \dots n$)**:
   For substring start $i = 1 \dots n - l + 1$ and end $j = i + l - 1$:
   For split point $k = i \dots j - 1$:
   $$P[i, j, A] = \text{true} \iff \exists (A \to B C) \in R \text{ s.t. } P[i, k, B] \land P[k+1, j, C]$$
3. **Acceptance Test**:
   $$w \in L(G) \iff P[1, n, S] = \text{true}$$

### Complexity:
- Time: $\mathcal{O}(n^3 \cdot |R|)$
- Space: $\mathcal{O}(n^2 \cdot |V|)$

## 5. Pumping Lemma for Context-Free Languages (CFLs)

Used to **prove a language is NOT Context-Free**.

### Statement:
If $L$ is a Context-Free Language, there exists an integer $p \ge 1$ (pumping length) such that any string $s \in L$ with $|s| \ge p$ can be written as $s = u v w x y$ satisfying:
1. $|v w x| \le p$
2. $|v x| \ge 1$ (at least one of $v$ or $x$ is non-empty)
3. $\forall i \ge 0, \quad u v^i w x^i y \in L$

### Canonical Example ($L = \{ a^n b^n c^n \mid n \ge 0 \}$):
1. Assume $L$ is context-free with pumping length $p$.
2. Choose $s = a^p b^p c^p \in L$.
3. Since $|vwx| \le p$, $vwx$ cannot contain all three symbols $a, b, c$.
4. Pumping $v$ and $x$ ($i = 2$) increases counts of at most two symbols, leaving unequalled counts.
5. Contradiction! Thus $L$ is **not context-free**.
